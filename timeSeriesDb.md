# Timeseries database
They are being used as columnar db with time as key.

## Line protocol
- `<measurementName> <tag1=v1,tag2=v2> <field1=v1,field2=v2> timestamp`

## examples
1. Amazon Timestream
2. CrateDB
3. InfluxDB
4. TimescaleDB
5. Prometheus
