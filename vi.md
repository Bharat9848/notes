# VIM
## Insertion mode
- `I` insert at the beginning
- `o` is for insert new line below our cursor line.
- `O` is for inserting new line above our cursor line.
- `A` is for appending at the end of cursor line.
- Insert mode - switch using (i/a)
## command-line mode
- `:x` is for save and exit
- `:w` is for write mode.
- `:set number` show line number
- `:set nonumber` hide line number
- `:syntax on` highlight syntax
- `:r <anotherFile>` read other file in current directory 
- `:<startlineno,endlineno>w <other file>` write line from start to end line number.
## selection mode
 - select whole file: `ggVV`

## Normal mode 
- switch using `esc`
- Navigation: 
  - `$` jump to end of line. 
  - `^` jump cursor to beginning of line. 
  - `w` jump to next word. 
  - `xw` delete current word. 
  - `b` jump to previous word

## Visual block mode 
- switch using `^v`
## Visual line mode 
- switch using `V`
## Visual mode 
- switch using `v`
## Replace mode 
- switch using `R`

## Files
- Vim open files are stored in buffers
- Vim have tabs each tab have window panes.
- One buffer can be opened in many panes to show different parts of files
